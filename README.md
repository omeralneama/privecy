سياسة الخصوصية

شكرًا لاستخدامك لعبتنا مزامنة الالوان نحن نولي أهمية كبيرة لخصوصيتك ونريد توضيح كيفية تعاملنا مع بياناتك.

١. جمع المعلومات لا نقوم بجمع أي معلومات شخصية مثل الاسم، البريد الإلكتروني، رقم الهاتف، أو أي بيانات تعريفية أخرى. لا نقوم بجمع بيانات الموقع الجغرافي أو معلومات الجهاز.
٢. استخدام البيانات نظرًا لأننا لا نجمع أي بيانات شخصية، فإننا لا نستخدم أي بيانات تخصك لأي غرض كان.

٣. خدمات الطرف الثالث قد تستخدم لعبتنا خدمات طرف ثالث، مثل محركات الألعاب أو الإعلانات، ولكنها لا تقوم بجمع أي بيانات شخصية من المستخدمين. يُرجى مراجعة سياسات الخصوصية الخاصة بالخدمات التي قد تكون مدمجة في اللعبة، مثل متجر التطبيقات أو منصات الإعلانات. 
٤. الأمان نحن ملتزمون بحماية تجربة المستخدم، ونضمن أن لعبتنا لا تقوم بتخزين أو مشاركة أي بيانات حساسة.
٥. تحديثات سياسة الخصوصية قد نقوم بتحديث هذه السياسة من وقت لآخر. سيتم نشر أي تغييرات على هذه الصفحة.
٦. الاتصال بنا إذا كان لديك أي استفسارات بخصوص سياسة الخصوصية، يمكنك التواصل معنا عبر البريد الإلكتروني: omeralneama@gmail.com.
